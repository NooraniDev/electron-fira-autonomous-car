# Primary Robot Photograph Placement

Place the official **ELECTRON** robot photograph in this directory using the exact filename:

```text
assets/images/robot-hero.png
```

## Image Specifications

- **Filename:** `robot-hero.png`
- **Aspect ratio:** `1:1` (square)
- **Recommended resolution:** `2048 × 2048` px or higher
- **Visual style:** Industrial studio product photography on a dark navy / graphite background

When `assets/images/robot-hero.png` is present, both the website (`index.html`) and the GitHub `README.md` automatically display it. When the file is not yet present, the website renders a clean architectural placeholder referencing `assets/images/robot-hero.png` without throwing broken-image errors.
