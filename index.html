01Platform Overview

Perception, decision, and motion in one autonomous system

Engineered specifically for the FIRA Robotics Competition, ELECTRON perceives its environment through onboard vision and proximity sensing, interprets visual markers and obstacles in real time, and executes precise motion without human intervention.

01

Visual Perception

Live camera acquisition paired with image preprocessing and deep-learning object recognition.

02

Fiducial Navigation

Recognition of standardized AprilTag 36h11 markers for navigation and traffic-related instructions.

03

Split-Compute Autonomy

High-level vision and decision-making on Raspberry Pi 5 decoupled from low-level microcontroller timing.

04

Untethered Operation

Onboard lithium-ion energy storage with regulated DC-DC power delivery across compute and motor stages.

04Hardware Architecture

Purpose-built subsystems from regulated power to optical sensing

Primary Compute

Raspberry Pi 5 (16 GB)

Central single-board computer executing camera acquisition, image processing, vision inference, and high-level navigation decisions.

Camera Input → Arduino Command Bus
Optical Sensor

Raspberry Pi Camera

Captures the live forward visual stream required for fiducial marker recognition, object detection, and path tracking.

Streams Frames → Raspberry Pi 5
Embedded Controller

Arduino Uno

Dedicated microcontroller handling deterministic, time-critical control loops and actuator signal generation.

Raspberry Pi 5 → L298 & Servo
Motor Power Stage

L298 Motor Driver

Dual H-bridge power stage amplifying low-current logic signals into regulated current for drive motor speed and direction.

Arduino Logic + Battery Rail → Drive Motors
Precision Actuator

Servo Motor

Closed-loop rotary actuator providing responsive, repeatable angular positioning for the steering linkage.

PWM Control ← Arduino Uno
Energy Storage

Li-ion Battery System

High-density rechargeable lithium-ion pack enabling untethered autonomous operation across competition runs.

Primary Bus → DC-DC & Motor Stage
Power Conditioning

DC-DC Voltage Regulation

Stabilizes battery voltage into clean supply rails, isolating sensitive compute hardware from transient motor loads.

Battery Pack → Compute & Sensors
Proximity Sensing

Obstacle Detection Sensor

Provides direct proximity awareness in the robot's path, complementing optical perception for collision-safe navigation.

Proximity State → Control Pipeline
