01Project Overview

An autonomous robot engineered for competition

ELECTRON brings perception, decision-making, and control together in one mobile platform that operates without human intervention.

What it is

An autonomous mobile robot that perceives its environment, interprets visual information, and moves through a competition field on its own — combining a vision-capable main computer with dedicated embedded control.

Why it was built

The robot was developed to compete in the FIRA Robotics Competition, where autonomous platforms are evaluated on their ability to navigate, recognize visual cues, and respond reliably under real competition conditions.

Autonomy objectives

  1. 01Perceive the environment through onboard vision and sensing
  2. 02Recognize visual markers and objects relevant to navigation
  3. 03Make autonomous decisions in real time
  4. 04Translate decisions into controlled, precise motion
  5. 05Operate reliably under competition constraints

Engineering domains

  • Autonomous Robotics
  • Computer Vision
  • Image Processing
  • Embedded Systems
  • Sensor Integration
  • Robotic Navigation
  • Object Recognition
  • Hardware/Software Integration

Competition context

FIRA is an international robotics competition in which teams design robots that must operate autonomously in structured environments. ELECTRON placed second at the Iran National FIRA Competition and qualified for the FIRA International Competition.

03Hardware Architecture

Integrated hardware, from power to perception

The robot combines a main computer for vision and decision-making, a microcontroller for real-time control, and dedicated power, actuation, and sensing subsystems.

Main Computing Platform

Raspberry Pi 5 (16 GB)

Function
A single-board computer that serves as the robot's primary processing unit.
Role in the robot
Runs the high-level software: image acquisition, image processing, computer-vision inference, and autonomous decision-making.
Relationships
Receives image data from the camera and passes high-level commands to the Arduino Uno for low-level control.
Vision Sensor

Raspberry Pi Camera

Function
Captures a live visual stream of the robot's surroundings.
Role in the robot
Provides the primary perceptual input for marker recognition, object detection, and navigation.
Relationships
Connected to the Raspberry Pi 5, which processes the captured frames.
Embedded Controller

Arduino Uno

Function
A microcontroller board dedicated to deterministic, low-level control tasks.
Role in the robot
Handles time-sensitive actuation, offloading real-time control from the main computer.
Relationships
Bridges the Raspberry Pi 5 and the actuation hardware — the L298 motor driver and the servo motor.
Motor Power Stage

L298 Motor Driver

Function
A dual H-bridge driver that delivers controlled power to the robot's drive motors.
Role in the robot
Converts low-power control signals into the current required for propulsion, direction, and speed control.
Relationships
Commanded by the Arduino Uno and supplied by the battery system.
Precision Actuator

Servo Motor

Function
A position-controlled actuator that moves to precise angular positions.
Role in the robot
Provides precise angular positioning within the robot's mechanical system.
Relationships
Positioned by control signals from the Arduino Uno.
Energy Source

Li-ion Battery System

Function
Rechargeable lithium-ion cells that supply onboard energy.
Role in the robot
Enables untethered, autonomous operation throughout a competition run.
Relationships
Supplies the entire robot; voltage regulation adapts its output to each subsystem.
Power Conditioning

DC-DC Voltage Regulation

Function
Converts battery voltage into the stable supply levels the electronics require.
Role in the robot
Protects sensitive computing hardware and keeps it stable under changing motor loads.
Relationships
Sits between the battery system and the computing and control electronics.
Proximity Sensing

Obstacle Detection Sensor

Function
Detects objects in the robot's path.
Role in the robot
Adds a sensing layer, independent of the camera, for collision-aware navigation.
Relationships
Its readings feed the control system so the robot can react to obstacles.

04Software & Technologies

The technology behind autonomy

A software stack built around real-time vision, embedded control, and autonomous behavior.

Programming Language

Python

The primary language of the robot's high-level software, chosen for its mature ecosystem in vision, machine learning, and rapid engineering iteration.

Vision Library

OpenCV

The open-source computer-vision library used for image acquisition, preprocessing, and classical vision operations.

Object Detection

YOLO

A real-time deep-learning object-detection architecture, used to recognize relevant objects within the camera stream.

Perception

Computer Vision

Allows the robot to interpret its surroundings from images — including standardized visual fiducial markers (AprilTag) used for navigation and traffic-related instructions.

Real-Time Control

Embedded Systems

Microcontroller-based control that handles direct, time-critical interaction with motors and actuators reliably.

Signal Processing

Image Processing

Techniques that clean, enhance, and transform raw camera frames into information the robot can act on.

System Integration

Autonomous Robotics

The integration of perception, decision-making, and control into a robot that operates without human intervention.
