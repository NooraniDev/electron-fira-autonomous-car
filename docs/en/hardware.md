## Overview

The **ELECTRON** robot uses a split-compute hardware architecture that separates high-level visual perception from deterministic low-level actuation, supported by an onboard rechargeable power system and proximity sensing.

> **Verification & Confidentiality Note:** Component relationships below are presented at a conceptual level. Exact pinouts, wiring schematics, and electrical parameters are intentionally omitted. Final competition configuration status is marked for team confirmation where applicable.

---

## Known Hardware Components

### 1. Raspberry Pi 5 (16 GB)
- **Subsystem:** Main Computing Platform
- **General Function:** High-performance single-board computer serving as the robot's central processing unit.
- **Role in the Robot:** Executes the Python software stack, camera frame acquisition, OpenCV image preprocessing, YOLO object recognition, AprilTag detection, and high-level navigation decision-making.
- **System Relationships:** Receives live frames from the Raspberry Pi Camera and sends high-level motion commands to the Arduino Uno.

### 2. Raspberry Pi Camera
- **Subsystem:** Vision Sensor
- **General Function:** Onboard digital camera module capturing a continuous visual stream of the environment ahead of the robot.
- **Role in the Robot:** Provides the primary perceptual input for navigation, visual marker interpretation, and object recognition.
- **System Relationships:** Interfaces directly with the Raspberry Pi 5 image processing pipeline.

### 3. Arduino Uno
- **Subsystem:** Embedded Controller
- **General Function:** Microcontroller board dedicated to real-time, deterministic input/output and control signal generation.
- **Role in the Robot:** Offloads time-critical motor and servo control from the main Linux computer so actuation remains responsive and predictable.
- **System Relationships:** Receives high-level commands from the Raspberry Pi 5 and drives the L298 motor driver and servo motor.

### 4. L298 Motor Driver
- **Subsystem:** Motor Power Stage
- **General Function:** Dual full-bridge (H-bridge) driver capable of controlling inductive motor loads.
- **Role in the Robot:** Amplifies low-current logic signals into the higher current required to control drive motor speed and direction.
- **System Relationships:** Driven by control signals from the Arduino Uno and powered by the onboard battery subsystem.

### 5. Servo Motor
- **Subsystem:** Precision Actuator
- **General Function:** Closed-loop position-controlled rotary actuator.
- **Role in the Robot:** Provides accurate angular positioning within the robot's mechanical system.
- **System Relationships:** Controlled via pulse-width modulated (PWM) signals generated by the Arduino Uno.

### 6. Li-ion Battery System
- **Subsystem:** Energy Source
- **General Function:** Rechargeable lithium-ion energy storage pack.
- **Role in the Robot:** Enables untethered operation across competition runs while supplying both high-draw actuators and computing electronics.
- **System Relationships:** Feeds the motor power stage and the DC-DC voltage regulation stage.

### 7. DC-DC Voltage Regulation
- **Subsystem:** Power Conditioning
- **General Function:** Step-down / regulated DC-DC conversion stage.
- **Role in the Robot:** Maintains stable voltage rails for the Raspberry Pi 5, Arduino Uno, and sensors even under transient motor current draw.
- **System Relationships:** Sits between the Li-ion battery system and the computing, sensing, and control electronics.

### 8. Obstacle Detection Sensor
- **Subsystem:** Proximity Sensing
- **General Function:** Onboard proximity sensor detecting physical obstacles in the robot's path.
- **Role in the Robot:** Supplements camera-based perception with direct obstacle awareness for safe navigation.
- **System Relationships:** Provides obstacle status to the control and decision-making system.
