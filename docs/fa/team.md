## مشارکت‌های مهندسی فردی — امیرعلی نورانی

این پورتفولیو حضور و مشارکت مهندسی **امیرعلی نورانی** را در توسعه‌ی ربات متحرک خودران **ELECTRON** برای مسابقات FIRA برجسته می‌کند.

حوزه‌های مشارکت پیشنهادی زیر برای بررسی فهرست شده‌اند و پس از تأیید نهایی به‌عنوان قطعی ثبت خواهند شد:

| ردیف | حوزه‌ی مشارکت | وضعیت |
| :--- | :--- | :--- |
| ۰۱ | توسعه‌ی نرم‌افزار رباتیک | _در انتظار تأیید_ |
| ۰۲ | بینایی ماشین | _در انتظار تأیید_ |
| ۰۳ | پردازش تصویر | _در انتظار تأیید_ |
| ۰۴ | یکپارچه‌سازی Raspberry Pi | _در انتظار تأیید_ |
| ۰۵ | سامانه‌های نهفته | _در انتظار تأیید_ |
| ۰۶ | یکپارچه‌سازی سخت‌افزار و نرم‌افزار | _در انتظار تأیید_ |
| ۰۷ | آزمون سامانه | _در انتظار تأیید_ |
